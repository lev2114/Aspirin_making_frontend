# Этапы синтеза аспирина — ЛР №5

SPA на React, TypeScript, Vite и React-Bootstrap. Интерфейс перенесён из Go HTML-шаблонов `aspirin_back/templates`; исходные стили и локальные изображения/видео скопированы из `aspirin_back/resources`. Redux и пользовательский Context не используются. Состояние передаётся через props.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (например, `nvm use 24`).

```sh
npm install
npm run dev
```

Открыть http://localhost:3000. `npm run build` создаёт сборку в `dist`, `npm run preview` открывает её локально. При размещении сборки сервер должен возвращать `index.html` для маршрутов SPA.

## Страницы, поля и кнопки

- **Лента** — `/aspirin-synthesis-stage`. Видео с элементами управления, название, описание, длительность, выход продукта и количество лайков. «Развернуть»/«Свернуть» меняет видимость полного описания. Стрелка показывает следующий этап; после последнего открывается первый. ID текущего этапа хранится в query-параметре `aspirin_synthesis_stage_id`, ссылка работает после обновления страницы.
- **Плитка** — `/aspirin-synthesis-stages`. Карточки с изображением, названием, длительностью и лайками. Ползунок «Длительность этапа, мин.» задаёт максимум от 0 до 30. «Применить фильтр» показывает этапы с длительностью не больше выбранной, «Сбросить фильтр» возвращает все. До применения ползунок не меняет список. Отображаются число результатов и сообщение для пустой выборки. Нажатие на изображение или название открывает выбранный этап в ленте. Применённый фильтр сохраняется при переходах между страницами до перезагрузки.

Снизу закреплена панель из четырёх пунктов: «Лента», «Добавление», «Плитка», «Вход». Доступны только «Лента» и «Плитка». Добавление и вход отключены. Изменение публикаций и лайков для гостя отсутствует.

## Данные и медиа

По умолчанию данные обеих страниц берутся только из `src/data/stages.ts`, без запросов к backend. В коллекции есть заполненные, пустые и `null` поля медиа. Демонстрационные численные значения не являются результатами реального эксперимента.

`StageImage` и `StageVideo` из `src/components/StageMedia.tsx` подставляют локальные `public/media/default.png` и `public/media/default.mp4`, если поле пусто, содержит пробелы или равно `null`. При ошибке загрузки указанного медиа также используется локальный файл; если недоступно и стандартное видео, выводится сообщение. В mock-режиме Network содержит только файлы приложения и локальные медиа.

## Подключение к Go API

Для базового показа ЛР оставьте mock-режим. Для подключения существующего сервиса скопируйте `.env.example` в `.env.local`, установите `VITE_USE_API=true`, запустите backend на http://localhost:8080 и перезапустите Vite.

`useStages` выполнит `GET /api/aspirin-stages` и прочитает массив `data`. Тип `Stage` соответствует JSON backend. Все страницы используют полученную коллекцию; фильтрация выполняется на клиенте. Vite проксирует `/api` на порт 8080, сохраняя префикс, поэтому отдельная настройка CORS для разработки не требуется. При ошибке показывается сообщение и кнопка «Повторить». Автоматической подмены ответа сервера mock-данными нет. Для production требуется аналогичный reverse proxy для `/api`; Vite proxy работает только в dev-режиме. Медиа API должны быть доступны по URL, возвращённым backend.

## Компоненты и хуки

- `App` хранит применённый предел длительности в `useState`, передаёт его и setter через props в `GridPage`, откуда они поступают в `DurationFilter` как `value` и `onApply`.
- `DurationFilter` хранит редактируемое значение в `useState`. Обработчик формы предотвращает перезагрузку и вызывает `onApply`; `GridPage` фильтрует коллекцию и передаёт каждый объект в `StageCard` через `stage`.
- `FeedPage` использует `useState` для раскрытия описания и `useSearchParams` для текущего этапа.
- `StageImage`/`StageVideo` используют `useState` для ошибок медиа. Ключи по ID этапа сбрасывают состояние при смене записи.
- `useStages` объединяет `useState` для коллекции, загрузки, ошибки и повторной попытки с `useEffect` для запроса API. Cleanup отменяет запрос через `AbortController` при размонтировании или повторной попытке. В mock-режиме эффект не делает запросов.
- `App` использует `useLocation` и `useEffect` для заголовка вкладки и прокрутки при смене страницы.

Маршрутизация реализована React Router. Компоненты Bootstrap: `Navbar`, `Card`, `Form`, `Form.Range`, `Button`, `Alert`, `Spinner`. Исходный мобильный макет сохраняет ширину 375 px и сжимается на меньших экранах.
